# Mapa simples (cada coisa no seu lugar)

BotFather (Telegram):
- Onde você criou o bot (já feito)
- Só precisa do token (já salvo no config.json)
- Não precisa voltar lá

Mercado Pago:
- Onde você configura o webhook (notificação de pagamento)
- Não é no Telegram
- É no painel do Mercado Pago (mercadopago.com.br/developers)

Render / ngrok:
- Onde o bot fica ligado 24h (online)
- Se você rodar no computador: usa ngrok
- Se subir no Render: não precisa de ngrok

Resumo:
- Telegram = BotFather (já feito)
- Pagamento = Mercado Pago (webhook)
- Bot online = Render ou ngrok
