# Deletar a pasta bot_ruby no GitHub (Passo a passo)

1. Acesse github.com e vá no seu repositório
2. Clique na pasta chamada bot_ruby
3. No canto superior direito, clique nos 3 pontinhos (...)
4. Selecione "Delete directory"
5. Confirme clicando em "Commit changes"

Pronto. A pasta foi deletada.
Agora você pode fazer upload dos arquivos diretamente (sem a pasta).
