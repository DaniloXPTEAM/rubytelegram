# ⚠️ Importante — Por que você precisa fazer uma parte no celular

O Telegram não deixa ninguém criar um bot "de longe". Só a pessoa que tem o aplicativo no celular pode falar com o @BotFather.

Mas é muito rápido. São só 4 mensagens:

1. Abre o Telegram
2. Procura `@BotFather`
3. Manda `/newbot`
4. Copia o TOKEN que ele te dá

Depois disso, você cola o token no arquivo `config.json` e eu faço TODO O RESTO no computador para você.

Eu não posso pedir o seu token aqui (é a chave da sua conta), mas você pode colar no arquivo `config.json` sem me mostrar. Assim que você fizer isso, me avisa e eu verifico se está funcionando.

Se você quer criar uma conta nova do Telegram só para isso, o processo é o mesmo. Você só precisa de um número de telefone para receber o código.
