# Corrigir erro de JSON no Render

O arquivo config.json no computador está correto.
O arquivo no GitHub está com erro.

Como corrigir:
1. No GitHub, abra o arquivo config.json
2. Apague todo o conteúdo
3. Copie todo o conteúdo do arquivo no computador (bot_ruby/config.json)
4. Cole no GitHub e salve

Ou, se preferir subir pelo computador:
1. No GitHub, clique em "Add file" → "Upload files"
2. Selecione o arquivo bot_ruby/config.json do computador
3. Clique em "Commit changes"
