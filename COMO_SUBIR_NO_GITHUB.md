# Como subir os arquivos no GitHub (para usar no Render)

Passo 1: Acesse github.com e crie uma conta (gratuito)
Passo 2: Clique em "New repository" (novo repositório)
Passo 3: Dê um nome (ex: bot-ruby)
Passo 4: Deixe público (Public) e clique em "Create repository"
Passo 5: No computador, abra a pasta bot_ruby/ e copie todos os arquivos
Passo 6: No GitHub, clique em "uploading an existing file"
Passo 7: Selecione todos os arquivos da pasta bot_ruby e clique em "Commit changes"
Passo 8: No Render, selecione "Git Provider" e escolha esse repositório

Pronto. O bot está no Render.
