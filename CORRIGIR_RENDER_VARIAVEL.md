# Corrigir variável de ambiente no Render

Se o arquivo no GitHub está correto mas o Render ainda mostra 'orubyfoxai':

1. No painel do Render, vá em "Environment" (variáveis de ambiente)
2. Procure a variável ADMIN_ID
3. Se estiver como 'orubyfoxai', apague ou troque para 123456789
4. Se não houver ADMIN_ID, não precisa adicionar (o bot usa o arquivo config.json)

Depois de corrigir, clique em "Manual Deploy" para atualizar.
