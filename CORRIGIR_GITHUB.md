# Como corrigir no GitHub (deletar a pasta e subir os arquivos diretamente)

Se você subiu a pasta bot_ruby/ para dentro do repositório:

Passo 1: No GitHub, vá no repositório
Passo 2: Clique na pasta bot_ruby/
Passo 3: Clique no ícone de lixeira (delete) para deletar a pasta
Passo 4: No computador, selecione os arquivos diretamente (não a pasta):
  - bot.py
  - requirements.txt
  - config.json
  - audios/
  - pacotes/
Passo 5: No GitHub, clique em "Add file" → "Upload files"
Passo 6: Selecione esses arquivos e clique em "Commit changes"

Assim os arquivos ficam direto na raiz do repositório,
e o Render encontra tudo automaticamente.
