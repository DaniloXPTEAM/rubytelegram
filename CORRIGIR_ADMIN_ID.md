# Corrigir admin_id no GitHub

O admin_id é o seu número do Telegram (ex: 123456789).
Não é do Instagram.

Como subir o arquivo corrigido:
1. No GitHub, vá no seu repositório
2. Abra o arquivo config.json
3. Edite a linha do admin_id para: 123456789
4. Salve

Ou, se preferir subir o arquivo do computador:
1. No GitHub, clique em "Add file" → "Upload files"
2. Selecione o arquivo config.json do computador (pasta bot_ruby)
3. Clique em "Commit changes"
